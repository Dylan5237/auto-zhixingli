# auto-zhixingli

面向浏览器网课的本地辅助工具项目：按课程与章节组织处理队列、采集**获准录制**的页签音频，并在本机转写、整理课程笔记。

> **当前状态：M0 技术验证待执行。** 本仓库目前只包含设计文档与只读诊断脚本，并非可运行的课程托管应用；尚未对目标公司平台做真实 DOM、录音或自动连播验证。

## 开发资料

- [V1.1 技术方案与 Codex 任务书](docs/course_assistant_mvp_v1_1.md)：架构、边界、M0～M3 阶段和 M0 验收标准。
- [M0 只读诊断脚本](tools/course_assistant_readonly_probe.js)：在浏览器 DevTools 控制台观察可访问的媒体事件与页面导航；**不录音，不修改进度**。

## 本地工作空间与 APO 初始化

约定 Windows 工作目录：`D:\_projects\tools\auto-zhixingli`。

此仓库作为项目事实源。请先将 GitHub 的 `main` 检出到上述目录，然后由本地 APO 机制执行工程初始化。**不要将 APO 的具体命令、配置文件或项目脚手架预先猜测并提交**；以你本地 APO 实际生成的结果为准。

初始化前请阅读 [任务书 M0 部分](docs/course_assistant_mvp_v1_1.md)：当前只验证播放器可观察性、同页签导航、页签音频采集及浏览器自动播放限制。**M0 未验收，不启动 M1～M3 实现。**

## 数据与合规边界

- 仓库是**公开仓库**：禁止提交课程音视频、逐字稿、内部培训资料、真实站点凭据、Cookie、Token、个人数据和未脱敏日志。
- 仅在公司许可下录音或保存课程资料；企业内容默认只在本地处理，不外传。
- 不伪造播放时长、学习进度、考试记录或人为在场验证；遇到登录失效、验证码、强制测试和播放限制时停止并提示用户。
- `.gitignore` 仅提供防误提交的基础保障，提交前仍需人工检查 `git status` 与差异内容。
