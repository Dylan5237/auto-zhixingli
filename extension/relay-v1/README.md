# 跨课程接力 v1（本地自用，Issue #11）

只接力一次 A → 指定 B：A 自然结束、平台明确显示整门课程完成后，点击原生“学习”导航 → 唯一目标 B → 详情页正常“开始学习”入口 → 确认 B 的原生媒体事件及播放时间实际推进（`playing`，或脚本晚加载时的原生 `timeupdate`；报告分别记录）。章节连播继续由平台处理；暂停、缓冲、接近片尾都不是课程完成。

## 安装 / 更新

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 加载本目录；已有扩展则点“重新加载”。版本应为 **0.2.0**。
3. 刷新课程页，右下角出现接力面板。更新增加的 `storage` 仅保存扩展自身配置和单页签接力状态，不读写网站存储。

无需构建、依赖安装或 Console。扩展只匹配原有课程站点；默认不自动点击。

## 一次人工操作采集 B

在同一个 Chrome 页签操作：

1. 手动进入课程列表，展开面板“首次配置”，点 **1. 选取目标 B**，再点 B 的**课程标题**，不要点图片或卡片空白。
2. 到 B 的详情页，点 **2. 记住开始入口**，再正常点击网站的“开始学习 / 继续学习”。
3. 等面板提示“已记住 B 的真实播放页”，然后手动返回课程 A 的播放页。配置只留在本机扩展存储，不需要复制选择器。

优先使用点选条目中实际存在的 `data-course-id` / `data-courseid` / `data-id`。否则记录所点标题的精确文本及实际 DOM 路径。重名、缺项、隐藏条目或无法唯一识别时停止，不按 `index` / 模糊文字 / 首条猜选。

## 运行 A → B

1. 在 A 播放页点 **启用 A → B**，让 A 正常播放至课程结束。必须在自然结束前启用；不快进，不伪造进度。
2. 首次遇到“无法确认整课完成”，仅当平台确实显示**整门课程**完成时，点 **3. 绑定整课完成标志**，再点该状态文字（如整课状态；不是章节完成、视频进度或累计学时）。接力会继续。
3. 没有明确课程级完成标志就保持未确认，不随意绑定其他文字；点“复制脱敏结果”回传即可。
4. 出现“本次接力完成：B 已有原生媒体事件且播放时间实际推进”才算扩展观察到 B 播放；本轮到此停止，不循环选课。

已绑定的整课完成标志仅在原页面地址、唯一可见元素及精确状态文本全部相符时生效；换课程后可能需重新绑定。B 的详情及播放页也使用实际采集的完整地址校验。如果不同课程共用同一地址，当前版本会拒绝从该地址启动，需补可验证的课程标识后适配，不能当作成功。

单活动页签；SPA、整页导航均在导航前保存状态。配置跨浏览器重启保留；正在执行的接力只保留到当前浏览器会话结束。不要复制页签并发运行。普通后退恢复页面会重新读取扩展状态。

## 停止与诊断

- **停止接力**立即取消后续接力，不暂停网站媒体、不修改学习记录。
- **复制脱敏结果**显示并选中简短 JSON，按 Ctrl+C 后回传；含阶段、动作次数、配置齐备性和事件时间，不含课程名、URL、媒体内容。
- **本机诊断（含页面信息）**另含真实选择器、课程文字和页面地址。仅在需要定位 DOM 时私下提供，**禁止发到公开 Issue/PR 或提交仓库**。
- 脱敏结果中的 `TARGET_PLAYING_CONFIRMED` 是本轮自动链路的终点；`halt` 后人工点播不追认成自动成功。

常见停止原因：

| 代码 | 意义 / 最小操作 |
| --- | --- |
| `COURSE_COMPLETE_TIMEOUT` | 整课完成未知；确认是否有平台课程级状态，不能拿章节完成替代 |
| `LIST_NAV_UNKNOWN` / `LIST_TIMEOUT` | 没有唯一“学习”导航或列表未出现；回传简短诊断 |
| `TARGET_NOT_UNIQUE` | B 不在列表或不唯一；在列表重新点选确切 B |
| `DETAIL_START_TIMEOUT` | B 详情地址或实际入口不匹配；重新采集 B 开始入口 |
| `TARGET_IDENTITY_UNKNOWN` | 播放页身份与采集不符；重新采集 B 正常播放路径 |
| `PLAYBACK_NOT_CONFIRMED` | 未观察到原生媒体事件 + 时间推进；可能缓冲或自动播放受限，人工处理；本轮不算自动成功 |
| `HUMAN_CHECK` | 考试、验证、登录等敏感环节；人工处理，不绕过 |
| `stale-run` / `another-tab` | 旧页面状态或其他页签正在接力；先停止另一页签，刷新后重启 |

## 验证边界

`node --test tests/relay-v1.test.cjs` 在仓库根运行。单元测试和本地合成浏览器用例不代表企业平台验收：必须取得真实 Chrome 的 A → B 自动链路，并由实际运行确认 B 播放，才能报告该目标达成。

无录音、网络外传、平台接口调用或进度/时长修改；不绕过考试、验证码、在场验证、登录或浏览器自动播放限制。Git push、合并、部署与阶段 Accept 仍需另行授权。
